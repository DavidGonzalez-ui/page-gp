## De qué trata

Una aplicación web para cargar datasets en CSV o Excel y generar un diagnóstico exploratorio inicial.

## Qué incluye el diagnóstico

- Estructura del dataset
- Tipos de variables
- Valores faltantes
- Duplicados
- Estadísticas descriptivas
- Visualizaciones

## Para quién es

Para una persona investigadora o estudiante que necesita conocer rápidamente las características de un conjunto de datos antes de analizarlo.
